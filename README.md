# Яндекс Практикум. Груминг-салон

Учебная конфигурация 1С:Предприятие 8.3 по курсу «Разработчик 1С расширенный».

Предметная область: груминг-салон (клиенты и питомцы, запись на услуги, склад, продажи).

Актуальная версия конфигурации: ветка `sprint-4`.
